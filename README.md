# Project 17 — Same Page, New Design
BSERC GenAI Internship · Week 2 · Section D

## Deliverables
- `before.html` — intentionally plain page, created without applying a design skill.
- `after.html` — redesigned responsive page using a documented frontend-design / Impeccable-inspired design process.
- `design-skill.md` — design brief, rationale and three-plus design changes.
- `prompts.md` — prompts used in order.

## Run
Open `before.html` and `after.html` directly in Chrome, Edge or Firefox. Both are self-contained and work offline.

## Three key design changes
1. **Typography and hierarchy:** the after page uses a large hero heading, eyebrow label and stronger size contrast so visitors understand the page structure quickly.
2. **Cards and spacing:** the after page uses a consistent three-card grid with more padding, rounded borders and hover feedback, making the three offerings easier to scan.
3. **Responsive design:** the after page switches from three columns to one column on narrow screens, preventing cramped text and horizontal scrolling.

Additional changes include a cohesive dark-plum palette, lime/pink accents, semantic HTML and reduced-motion support.
